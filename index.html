ok boot net

Software for old and unusual computers

A network boot server and two emulators, built to boot and run vintage Sun, HP and DEC machines, real or emulated, with packages for Debian, Ubuntu and macOS.

Projects

gobootd

Network boot server

Boots old and unusual machines over the network, every protocol answering from one description of each client.

  • RARP, RMP, Sun ND, TFTP, bootparam, NFSv2, NIS
  • bootbridge: Ethernet over UDP or L2TPv3, for emulators
Releases Source

tme

The Machine Emulator

Emulates Sun workstations well enough to boot their PROMs and run SunOS and NetBSD: Sun-2, Sun-3, SPARCstation (sun4c) and UltraSPARC.

  • GTK display with media menu, screenshots and recording
  • SIMH tape images, Sun disk labels, Ethernet over UDP and L2TPv3
Releases Source

gxemul

GXemul

Emulates DECstations, SGI, LUNA-88K and many other machines, from MIPS to ARM and M88K.

  • Real TURBOchannel option ROMs, SIMH tape images
  • Ethernet over L2TPv3, screenshots and recording
Releases Source

Install

Debian and Ubuntu

A signed apt repository, for amd64 and arm64.

# once
sudo curl -fsSLo /usr/share/keyrings/rpajarola.gpg \
  https://rpajarola.github.io/apt/rpajarola.gpg
echo "deb [signed-by=/usr/share/keyrings/rpajarola.gpg] \
https://rpajarola.github.io/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/rpajarola.list
sudo apt update

sudo apt install gobootd tme-rp gxemul-rp
apt repository

macOS

A Homebrew tap, or an installer package from a project's releases page, which needs no Homebrew.

brew install rpajarola/tap/gobootd
brew install rpajarola/tap/tme-rp
brew install rpajarola/tap/gxemul-rp
